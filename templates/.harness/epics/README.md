# Epic chapters

Each Epic is a finite chapter in the continuing project story. It must have a user-visible outcome, starting condition, ending demo/acceptance condition, explicit scope boundaries, dependencies, and a Product Owner-approved maximum WU count.

No universal WU-count or time budget is assumed. If the approved budget is exhausted before the terminal condition is met, stop and request an owner-led rebase. Do not add WUs automatically. A later Epic may extend the story only after its purpose and place in the chapter sequence are approved.

Use `../templates/EPIC.md` as the contract skeleton.
